Rendering

Drawing with the uber shader

Every object in a scene is drawn by one pipeline, rasm.slang, with at most three indirect draw calls. The draw calls carry no vertex buffers and no per-object state. The shader finds everything it needs by following pointers that start in a 16-byte push constant.

In short

  • drawScene binds the pipeline, the bindless texture set and the geometry pool's index buffer once. Then, per cull-mode run: setCullMode, a push constant, one indirect draw.
  • The push constant is {SceneData address, firstDraw}. SceneData holds the camera, the lights and the addresses of all GPU tables.
  • Vertex pulling: vertMain finds its draw (DrawIndex + firstDraw), its instance (firstInstance) and its vertex (SV_VertexID + vertexOffset) itself. The pipeline has no vertex input.
  • fragMain reads the material row and branches: shadeUnlit or shadePBR.
  • shadePBR: glTF metallic-roughness, up to 8 lights, normal mapping, Reinhard tone mapping. The sRGB swapchain encodes the output.

1What drawScene records

The indirect draw is drawIndexedIndirectCount. It reads DrawInfo rows from the call's visible-draw buffer, starting at the run's first draw, and the number of rows from the count that culling wrote. Without the culling pipelines, it is drawIndexedIndirect over the whole run. See GPU frustum culling.

Before recording, drawScene checks

  1. Valid camera and scene. Otherwise it logs an error and draws nothing.
  2. Something to draw. An empty draw list, or one not yet uploaded to this frame slot, draws nothing. The pass keeps its clear color.
  3. The pipeline exists. On first use, Engine::createPipeline compiles shaders/passes/rasm.slang (vertMain, fragMain). If that fails, it logs and tries again next frame, so a shader fixed on disk is picked up while the app runs.
  4. Matching formats. A render target must have the swapchain's color format and D32_SFLOAT depth, like the pipeline.
  5. A free call slot. At most MAX_SCENE_DRAWS_PER_FRAME (8) calls per frame. Each call writes its own SceneData, because the GPU reads them only after the whole frame is recorded.

6The PBR shading in pbr.slang

  1. Sample the textures. Each texture is used only when its index is not INVALID_TEXTURE_INDEX (hasTexture). Base color = factor × texture. Roughness = G channel × factor, metallic = B channel × factor (glTF packing). Occlusion = R channel, mixed with 1 by strength. Emissive = factor × texture.
  2. Find the normal. With a normal texture, getNormalFromMap bends the normal (below). A back face of a double-sided surface uses the reversed normal.
  3. Base reflectance. f0 = 0.04 for non-metals, the base color for metals (lerp by metallic). Roughness is clamped to [0.045, 1].
  4. Loop over the lights. Up to numLights, at most MAX_LIGHTS = 8. Cook-Torrance: D_GGX × V_SmithGGXCorrelated × F_Schlick for specular, Lambert for diffuse, times color × intensity × attenuation × N·L.
  5. Ambient. A flat 0.03 × diffuse color × occlusion. There is no image-based lighting.
  6. Tone map. Reinhard: c / (c + 1). Alpha is the base color alpha. The sRGB swapchain encodes the result; the shader never applies the sRGB curve.

Directional light

L = −direction. No attenuation. direction points from the light toward the surface.

Point light

L = toward position. Attenuation = 1 / distance². When range > 0, a smooth window brings it to 0 at range. A range of 0 means no limit.

Normal mapping and the tangent sign

Mesh has tangents (|w| = 1)

Use the authored frame. T is made orthogonal to N again (interpolation bends it). B = cross(N, T) × sign(w), as glTF defines. The vertex shader already multiplied w by the handedness, so mirrored instances stay correct.

No tangents (w = 0)

Build T and B from screen-space derivatives of the position and the UV (ddx, ddy). B points toward decreasing v, because glTF normal maps store +Y as "up" in the image. Mirrored UV islands keep the right handedness.

7Why one pipeline serves everything

What changes per draw: data

Mesh, transform and material are rows in GPU tables, found by index. Textures are slots in one descriptor array. Cull mode is dynamic state (setCullMode). So no draw needs another pipeline, another vertex layout or another descriptor set.

What is fixed: pipeline state

Triangle list, no vertex input, depth test and write with GREATER_OR_EQUAL (reversed-Z), no blending, one color attachment in the swapchain format, D32_SFLOAT depth, front faces counter-clockwise.

The cost of this design is that every pixel runs the general shader, and the fixed state limits what a material can be. There is no blending, so there is no transparency today: alpha is written, not blended.

Known issues
  • P9: fragMain copies the whole material and all 8 lights into a PBRInfo local, which raises register pressure.
  • P8: the shaders are compiled from source at every launch, with no pipeline cache.
  • D12: the shader is Vulkan-only. getDrawIndex uses spirv_asm, and all data access uses raw pointers (buffer device address).

9Rules when you change it

Keep these true
  • Any change to SceneData, DrawInfo, InstanceData, MaterialData, VertexFull or PushConstants changes both sides: uberMaterialTypes.h, core.slang, the static_asserts and validateRasmStructs. Follow the struct contract.
  • The push constant stays 16 bytes (PUSH_CONSTANTS_SIZE). Add new per-call data to SceneData, not to the push constant.
  • Shaders output linear color. The sRGB swapchain does the encoding.
  • vertMain must add draw->vertexOffset to SV_VertexID; Slang has already removed it.
  • Verify shader changes by running the examples with enableValidation = true. A change that adds validation messages is not done. Shaders load at startup, so no rebuild is needed.
