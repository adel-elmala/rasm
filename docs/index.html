Documentation

RASM docs

RASM (رسم) is a GPU-driven rendering engine in C++20, with a Vulkan 1.4 backend and Slang shaders. The documentation has two parts: the API reference, to build applications with RASM, and the guides, to learn how it works inside.

API reference →For application developers. Link RASM, write a first program, then every public type and function, with examples. Guides →For learning and for contributors. One rendering technique per page, explained with pictures, then tied to RASM's code.
