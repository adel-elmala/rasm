RASM docs

RASM (رسم) is a GPU-driven rendering engine in C++20 with a Vulkan 1.4 backend and Slang shaders. These pages explain how it works inside, with pictures first, and how to build an application with it.

Guides →For engine developers. An engine tour, then one idea per page (culling, bindless, render graphs, …), each explained on its own and then tied back to RASM's code. API reference →For application developers. Every public type and function, with examples.

The engine on one page

Each box is a guide. Click one to open it. The top row runs on the CPU, the middle row on the GPU. Boxes with an orange border are tour pages that show how RASM fits together; the others explain one idea each.
