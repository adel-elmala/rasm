RASM docs

RASM (رسم) is a GPU-driven rendering engine in C++20 with a Vulkan 1.4 backend and Slang shaders. These pages explain how it works inside, with pictures first, and how to build an application with it.

Engine tour →Three pages that show how RASM fits together. Start here to work on the engine. Concept guides →One idea per page (culling, bindless, render graphs, …), explained on its own, then tied to RASM's code. API reference →For application developers.
