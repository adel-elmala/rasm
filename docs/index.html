RASM docs

RASM (رسم) is a GPU-driven rendering engine in C++20 with a Vulkan 1.4 backend and Slang shaders. These pages explain how it works inside, with pictures first, and how to build an application with it.

Guides →For engine developers. One topic per page: how data reaches the GPU, how culling works, how a frame runs. API reference →For application developers. Every public type and function, with examples.
